# Playground design specification

Concept: playground-concept.png, generated with the built-in Image Gen tool. Reference only; production artwork is deterministic SVG as specified in the approved technical plan.

Palette: warm off-white #f7f5ee, ink #20211e, purple #6842ed; thin ink rules, no shadows. Geometric preset colours: purple, green, orange and cobalt. Type: Space Grotesk, heavy editorial heading; IBM Plex Mono for addresses, labels and technical status. Nav: Playground, Gallery, Explorer, Network, Token.

Primary composition: simple brand/nav header, factual devnet status strip, large two-line heading, open NFT/meme form left and wallet rail right, separated by a single vertical rule. Four square selectable presets; name/symbol inputs; full-width mint control. Bottom recent-activity rail and footer. Mobile stacks wallet and form with no horizontal overflow.

Allowed visible copy: Solana Classic; Experimental devnet · 1 operator · TEST has no monetary value; Connection pending; Make something worth sharing.; A playground for memes and NFTs.; Meme token; NFT; Name; Symbol; Choose a geometric preset; Mint test NFT; Your test wallet; Create a disposable wallet to get started. Reloading this page loses access to it.; Create test wallet; Get 1 TEST; Balance; Recent activity; Your confirmed transactions will appear here.; Open to everyone. Built for memes and NFTs.

Functional deviations from the concept: mint is disabled until actual network identity and test wallet are verified; status reflects actual API health; balance and receipts never use invented data. Transfer controls and incomplete-issuance Resume are required additions from the approved plan. The community-token footer shows Not launched until an actual launch package exists, rather than implying prepared work is already complete.

The concept includes subtle generative shading on geometric art; production SVG uses flat deterministic shapes to preserve the explicit four-preset technical contract. No other visual reinterpretation is planned.
