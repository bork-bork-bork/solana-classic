# Security reports

Please report vulnerabilities privately through GitHub's private vulnerability
reporting feature when it is enabled for this repository. If no private reporting
channel is available, contact the repository owner through their public profile
to arrange one before sharing exploit details. Do not post keys or working
exploits in public issues.

The currently deployed network is a single-operator experimental devnet. Its
test units have no monetary value or promised conversion to SOC. Native mainnet,
production SOC and the proposed bridge are separate, unreleased systems.

Private signing keys, hosting credentials, runtime databases, ledgers and backup
archives must never be submitted as issue attachments or commits. Sanitized
evidence should identify the affected version and scope without those values.
